**Phase 0 — Foundation (Current → 2 weeks).** Complete planning documents. Finalise formula calibration with real data. Set up production infrastructure. Establish Claude Projects.

**Phase 1 — Core Platform (2–6 weeks).** Build production web app. Port formula engines from Lab. Strava OAuth. Route library with map. Athlete dashboard. Deploy.

**Phase 2 — Content & Polish (1–2 weeks).** Route descriptions. Social accounts. Privacy policy and terms. Monitoring. Internal testing with V and 3–5 trusted athletes.

**Phase 3 — Soft Launch (1–2 weeks).** 20–50 Peninsula athletes. Monitor everything. Fix issues. Adjust benchmarks.

**Phase 4 — Public Launch.** Open registration. Social media and Strava Club announcements. First Time Trial within 2 weeks.

**Phase 5 — Growth (Ongoing).** Expand route library. Subscription tiers. Formal events with leaderboards. Partnerships.

### V1b Milestone Definition `[LOCKED]`

V1b is complete when a real person can be sent to the site and have a coherent, compelling experience.

**Four required criteria:**
1. Map polish complete — 3D terrain, hillshade, fog, route lines with grade colours, marker states T1–T3, zoom transitions smooth.
2. Email capture live — POPIA-compliant newsletter signup.
3. About page live — origin story, platform vision, the four systems, the founder.
4. Coming soon components — real UI placeholders showing route grading, RPS, race readiness.

### Build Milestones

**V1b — Public Ready (Active).** Map polish, email capture, About page, coming soon, beta user gate.

**V2 — Intelligence & Integration.** GPS Stream Processor and Route Analyzer in production. Strava/Garmin OAuth. RPS live. Athlete profiles. Race Readiness. Dashboard. Events. Shop. First race partnership.

**V3 — Leaderboards, Social & Scale.** Full leaderboard system. Club features. Social layer. Locked map zones. Performance Zone alerts.

**V4 — Game Maker Licensing.** RMM model licensed globally.

### Build Sequence (Non-Negotiable)

Phase 1: GPS Stream Processor → Phase 2: Route Grading → Phase 3: RPS → Phase 4: Race Readiness. Each system feeds the next.
