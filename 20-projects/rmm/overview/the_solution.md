RMM is built on four interconnected formula systems and one live interactive map. Every system feeds the next. The map is the interface. The engine is the intelligence underneath it.

**System 1 — GPS Stream Processor.** Processes every GPS activity file from first principles. Calculates RMM Moving Time independently from platform-reported values. Corrects elevation data against a Digital Elevation Model. Derives all terrain metrics. See Section 3.2.

**System 2 — Route Grading System (V3).** Assigns every route an objective Difficulty Class (A through F), a Terrain Difficulty Score (1–10), and an Effort Descriptor. Pure GPS grading — no manual curator tags, no subjective input. See Section 3.3.

**System 3 — Runner Performance Score (RPS).** A proprietary athlete fitness score on a 90-day rolling window with continuous exponential decay. Five components at locked weights. See Section 3.4.

**System 4 — Race Readiness Engine.** Assesses whether a specific athlete is prepared for a specific route. Five checks with percentage-to-threshold visibility. See Section 3.5.
