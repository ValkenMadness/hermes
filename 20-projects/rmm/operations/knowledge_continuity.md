Each conversation has a focused scope. At the end, V types WRAP UP → log entry produced → pasted into canonical document → next conversation reads log before starting. This pattern is proven across 7+ Formula Log entries and months of development.

Extend to all functions: Content Log, Build Log, Strategy Log. Same format: date, focus, decided, tested, locked, open, next.

### The Context Injection Pattern

1. Project instructions provide standing context.
2. V provides task-specific context.
3. Reference documents attached when needed.
