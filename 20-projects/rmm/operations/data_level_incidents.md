**Incorrect scores produced:** Fix bug. Re-process affected activities. Notify athletes proactively. Transparency builds trust.

**Activity data corrupted/lost:** Check backups (max 24-hour loss). Re-sync from Strava/Garmin. Be honest if unrecoverable.

**False positive anti-gaming flag:** V reviews manually. Clear flag and re-process if legitimate. Adjust thresholds if systematic. Never penalise without manual review for "review" severity flags.
