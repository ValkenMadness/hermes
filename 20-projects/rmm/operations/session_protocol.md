**Opening:** Read Build Log → pull relevant files → confirm session goal → state blockers → build.

**Wrap-up:** Every file changed (exact paths), every feature built, every decision made (with reasoning), current state, next steps, security check.

**Principles:** Build strong and build once. The right answer, not the quickest. Security never compromised. Read before write. Test before declaring done. One focused task per conversation.
