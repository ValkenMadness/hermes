- Every metric from API only — no estimates, no guesses
- Unreliable metrics excluded — reliability over coverage
- Score degradation is intentional — fitness not maintained is not real
- All formula values in env vars only — never in code, comments, or variable names
- Leaderboards from official events only — training data never enters competitive ranking
- All pace arithmetic in seconds — no decimal minutes
